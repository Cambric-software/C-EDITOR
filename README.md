# Homework & Document Studio

First run: open PowerShell in this folder and execute python run_studio.py.
It opens the editor and creates or refreshes the Homework & Document Studio
shortcut on your Windows desktop. Afterward, use that icon whenever you want.
You can also double-click Homework_Document_Studio.bat.

Optional free enhancements:
python -m pip install reportlab python-docx pillow arabic-reshaper python-bidi

- reportlab: PDF export
- python-docx: Word DOCX export
- pillow: PNG, JPG, and WEBP artwork output
- arabic-reshaper and python-bidi: enhanced Arabic PDF shaping

All project editing, autosave/recovery, templates, local artwork, text, HTML,
SVG, and the desktop shortcut work without optional packages.
