# C EDITOR

A document and creative suite built with Flutter.

## Departments

- **Documents**: rich-text editor with templates and save/load
- **Design**: drag-and-drop canvas with shapes, text, colors
- **Spreadsheet**: grid with SUM and AVERAGE formulas
- **Slides**: presentation builder with presenter mode
- **Video**: multi-track timeline editor
- **Animation**: frame-by-frame studio

## Architecture

Built on the Cambric app-template with shared `cambric_design` package.

## Run

```bash
cd app && flutter run
```
